2)Go to command prompt
*Go to cd .ssh--->dir--->
*Go to puttykeygen--->conversions--->import key--->select divya.key--->conversions--->ExportopenSSHkey--->save as divya.pem--->save
*In command prompt --->cd desktop-->dir---> in this we find all files like divya.key,divya.ppk,divya.pem
*copy the path where these files are found
*ssh -i c:\users\divya\desktop\divya.pem divya@192.168.1.66--->we entered into that user without password in command prompt.
